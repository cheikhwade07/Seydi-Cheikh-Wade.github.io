# seydi-cheikh-wade.github.io

Personal portfolio for Seydi Cheikh Wade, now migrated to a Vite + React + TypeScript build.

## Development

```bash
npm install
npm run dev
```

## Verification

```bash
npm run typecheck
npm run lint
npm run build
npm run preview
```

The GitHub Pages deployment workflow builds from `main` and publishes the Vite `dist/` artifact.

Legacy single-file handoff context is preserved in `legacy/index.html` and `handoff/`.
