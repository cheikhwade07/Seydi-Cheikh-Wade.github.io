Soki

AI-powered study platform for active recall, adaptive review scheduling, and faster retention.

Overview: Soki is an AI-powered study platform built during the Carleton MindHack Hackathon. It helps students turn uploaded notes, slides, and PDFs into active recall material such as flashcards, quizzes, and problem-solving questions, then schedules review sessions with an FSRS-based spaced repetition workflow. The result is a study system that adapts to performance over time instead of behaving like a static flashcard generator.

Problem

Students often spend hours rereading notes and lecture material, but passive review does not reliably build long-term retention. What is usually missing is a workflow that pushes recall, supports multiple forms of practice, and adjusts future review timing based on how well the student is actually performing.

Solution

Soki processes uploaded study material through a backend pipeline that extracts content, generates study items with Gemini, stores user progress in PostgreSQL, and recalculates future review timing based on user feedback and review results. This creates a study loop that is active, personalized, and performance-aware from upload through revision.

Key Features

  • Upload study material including notes, slides, and PDFs
  • Generate flashcards, quizzes, and problem-solving questions with AI
  • Review material through an active recall interface
  • Adapt review timing with an FSRS-based spaced repetition scheduler
  • Plan sessions with calendar-based review scheduling
  • Support authentication and persistent user progress
  • Deploy the application as a live web product

Tech Stack

Next.js, FastAPI, PostgreSQL, Gemini API, FSRS-based review scheduler, authentication, deployed web application.

Technical Highlights

  • Not a one-shot generator: Soki supports multiple study formats and an adaptive review workflow rather than stopping at content generation.
  • Backend processing pipeline: uploaded material is processed, transformed into study content, stored with user-specific state, and tied back into future scheduling decisions.
  • Adaptive scheduling: review timing changes based on user performance and explicit feedback, keeping material in circulation when it is weak and spacing it out when retention improves.
  • Full-stack delivery under time pressure: the project combined frontend UX, backend services, persistent storage, auth, and deployment within a 36-hour hackathon window.

Impact / Outcome

Soki was shipped in 36 hours and won Winner - AI Automation Challenge and Runner-up - Best Language Cognition at the Carleton MindHack Hackathon. The project stood out because it delivered a usable study workflow with adaptive logic, persistence, and multiple content formats rather than a demo limited to static flashcard generation.
